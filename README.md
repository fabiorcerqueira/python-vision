# Python Vision

Site estático com módulos didáticos interativos para ensino visual de Python.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `python-vision`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve. O GitHub exibirá o endereço público do site após a publicação.

O arquivo `index.html` é a página inicial.
